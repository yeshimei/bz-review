# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 用 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 添加 `yeshimei/bz-review`，或手动下载 Release 里的 `main.js`、`manifest.json`、`styles.css`，放进 `<你的库>/.obsidian/plugins/bz-review/`。
3. 启用后左侧出现日历勾图标，点开就是复习计划。
