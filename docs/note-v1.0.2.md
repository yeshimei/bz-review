# 更新日志

发布日期：2026-11-21

## ✨ 新增

- **复习工作台** ：双栏布局，内容区与侧栏分开；一轮里五种卡片形态混排，切到哪张就实时换成哪种题面。
- **五种复习方式** ：抽认卡、做题、填空、上下文、展开全文，每张卡各记各的方式。
- **四种加卡来源** ：选中文字、划线一键、手动写、Markdown 导入，都能在两步内进计划。
- **统一加入流程** ：笔记、选段、文件夹、阅读器、手动创建都走同一条流程——选方式、审题面、确认才入库。
- **从阅读器挑内容** ：按划线或章节挑，AI 只挑值得长期记住的句子；确认页先看清范围与字数再开始。
- **书架复习页签** ：装了 bz Reader 后，书架多一个「复习」页签，挑内容、制卡、复习都在一起。
- **文件夹监听** ：盯住指定文件夹，新笔记自动排进计划。
- **Anki 导入** ：直接读官方导出的 apkg，按名配对媒体，遮挡卡也能一起进来。
- **卡片模板与媒体** ：正反面字段自选，能放图片和音频；图片遮挡卡点一下揭示。
- **牌组与标签** ：自建牌组、随手打标签，筛选和按书档案都认。
- **AI 重新生成** ：卡片正反面可改，也能让 AI 按当前内容重出一版。
- **FSRS-7 排期** ：长期与短期双稳定性加难度动态描述，按目标留存率反推下一次间隔。
- **学习步骤** ：新卡和重学先走 1 分钟加 10 分钟，毕业才进 FSRS，可改可关。
- **参数拟合** ：34 个权重随复习记录自动拟合，也能手填；目标留存率默认 90%，可调。
- **间隔抖动** ：2.5 天以上的间隔前后随机挪一点，把扎堆到期的卡摊到相邻几天。
- **提前与逾期** ：留存率掉到阈值以下提前进本轮；逾期有每日上限与常驻提醒。
- **假期** ：设一个结束日期，之前不提醒、不算逾期，回来计划整体顺延。
- **负荷预测** ：按未来 30 天排程算出每天复习量，提前看到哪天要挤时间。
- **记忆分析** ：忘坡、水位、欠账、阶石、墨晶、矿层、批改环与四驻，把整库状态画成一张图。
- **统计** ：复习量账本、24 小时与星期节律、近一年热力、逾期分档，徽章单列成就页。
- **按书档案** ：按书名或文件夹汇总卡片数、章节数、留存率、忘了率与逾期，一键导出 Markdown 报告。
- **卡片管理器** ：搜索筛选、挂起、埋藏、恢复、手动排期、移出；挂起和埋藏不改 FSRS 排期。
- **备份与回滚** ：多份自动备份，任意时间点回滚，回滚前再留一份快照。
- **导出** ：整包 JSON、CSV、统计 CSV、划线卡导出成笔记，都能一键拿走。
- **听卡片** ：用你自己的本地 TTS 朗读，离线可用、不按次收费；合成结果缓存。
- **跳回原文** ：揭示答案后跳回 bz Reader 里那一句，老版本推来的卡也能兜底。
- **成就与更多菜单** ：筛选、数据、设置、成就和批量选择收进更多菜单，窄屏也不挤。
- **英文界面** ：插件界面、命令、通知和设置都支持英文，语言跟着 Obsidian 走。

> 基础版与高级版只有数量上限不同（笔记与划线合计 50 条），功能完全一样，以后新增的功能也一样。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 用 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 添加 `yeshimei/bz-review`，或手动下载 Release 里的 `main.js`、`manifest.json`、`styles.css`，放进 `<你的库>/.obsidian/plugins/bz-review/`。
3. 启用后左侧出现日历勾图标，点开就是复习计划。
