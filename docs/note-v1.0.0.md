# 1.0.0

发布日期：2026-11-18

## 新增

- **复习工作台**：双栏布局，内容区与侧栏分开；一轮里五种卡片形态混排，切到哪张就实时换成哪种题面。
- **五种复习方式**：抽认卡、做题、填空、上下文、展开全文，每张卡各记各的方式。
- **听卡片**（高级版）：用你自己的本地 TTS 服务朗读卡片，离线可用、不按次收费；合成结果缓存，换卡自动释放。
- **回到原文**（高级版）：揭示答案后跳回 bz Reader 里那一句；老版本 Reader 推来的卡也能靠卡片钥匙兜底。
- **按书档案**（高级版）：按书名／文件夹汇总卡片数、章节数、留存率、忘了率与逾期，一键导出 Markdown 报告。
- **卡片管理器**（高级版）：搜索筛选、挂起、埋藏、恢复、手动排期、移出；挂起和埋藏不改 FSRS 排期。

## 改进

- Reader 推卡时带上跳回原文的链接与前后文，联动链路完整闭合。
- 记忆分析覆盖留存率、稳定性、难度、评级分布、连续天数、未来排程与逾期清单。
- 手机端工作栏自动收起，卡片占满屏幕，筛选控件换行不截断。

## 修复

- 卡片管理器五颗操作按钮的图标此前未渲染，已补上图标挂载。
- 窄窗口下筛选栏「不限状态」被挤压成半截字，已改为放不下就换行。
- AI 偶尔只回半句填空，现在降级为看原文，不再让用户背残句。

> 基础版与高级版的功能对照见仓库 `assets/plan-compare/shots/pro-compare.png` 与 README。
