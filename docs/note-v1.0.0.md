# 更新日志

发布日期：2026-11-21

## ✨ 新增

- **复习工作台** ：双栏布局，内容区与侧栏分开；一轮里五种卡片形态混排，切到哪张就实时换成哪种题面。
- **五种复习方式** ：抽认卡、做题、填空、上下文、展开全文，每张卡各记各的方式。
- **统一加入流程** ：笔记、选段、文件夹、阅读器、手动创建都走同一条流程——选方式、审题面、确认才入库。
- **从阅读器挑内容** ：按划线或章节挑，AI 只挑值得长期记住的句子；确认页先看清范围与字数再开始。
- **Anki 导入** ：直接读官方导出的 apkg，按名配对媒体，遮挡卡也能一起进来。
- **卡片模板与媒体** ：正反面字段自选，能放图和音频；图片遮挡卡点一下揭示。
- **牌组与标签** ：自建牌组、随手打标签，筛选和按书档案都认。
- **备份与回滚** ：多份自动备份，任意时间点回滚，回滚前再留一份快照。
- **FSRS-7 排期** ：按记忆稳定性排期，参数随你的复习记录自适应拟合，越用越准。
- **按书档案** ：按书名或文件夹汇总卡片数、章节数、留存率、忘了率与逾期，一键导出 Markdown 报告。
- **卡片管理器** ：搜索筛选、挂起、埋藏、恢复、手动排期、移出；挂起和埋藏不改 FSRS 排期。
- **成就与更多菜单** ：筛选、数据、设置、成就和批量选择收进更多菜单，窄屏也不挤。

## ⚡ 优化

- **听卡片** ：用你自己的本地 TTS 服务朗读，离线可用、不按次收费；合成结果缓存，换卡自动释放。
- **回到原文** ：揭示答案后跳回 bz Reader 里那一句，老版本 Reader 推来的卡也能靠卡片钥匙兜底。
- **学习步骤** ：新卡与重学步骤对齐 Anki 的 1 分钟加 10 分钟，新卡与逾期卡分开限额。
- **手机端** ：工作栏自动收起，卡片占满屏幕，筛选控件换行不截断。
- **记忆分析** ：留存率、稳定性、难度、评级分布、连续天数、未来排程与逾期清单都在一处。
- **弹窗收口** ：8 个弹窗统一头尾与焦点行为，窄屏激活码输入框铺满整行。

## 🐛 修复

- **重复加入** ：查重认「整篇钥匙」，同一篇笔记不会因为入口不同进两份。
- **预设方式** ：只跳过「选方式」，题面仍然必须人审，AI 出的内容不绕过人的眼睛。
- **额度到顶** ：弹同一份对照窗引导升级，不再显示「加入失败，请重试」。
- **卡片管理器** ：五颗操作按钮的图标此前未渲染，已补上图标挂载。
- **窄窗口** ：筛选栏「不限状态」被挤压成半截字，已改为放不下就换行。
- **填空卡** ：AI 只回半句时降级为看原文，不再让用户背残句。

> 基础版与高级版只有数量上限不同（笔记与划线合计 50 条），功能完全一样，以后新增的功能也一样。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 用 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 添加 `yeshimei/bz-review`，或手动下载 Release 里的 `main.js`、`manifest.json`、`styles.css`，放进 `<你的库>/.obsidian/plugins/bz-review/`。
3. 启用后左侧出现日历勾图标，点开就是复习计划。
