## 一、多份备份 + 任意时间点回滚弹窗

`feat: 多份备份与任意时间点回滚弹窗（备份/回滚二次确认，回滚前自动留快照）`

- 新增独立弹窗「备份与回滚」（命令 `review-backup`），列出全部自动快照 + 手动备份，每条带时间、来源、条数，点任意一份即可回滚。
- **备份二次确认**：点「立即备份」先弹「现在备份一次？」确认框。
- **回滚二次确认**：点「回滚到这里」先弹确认框，危险按钮红色且默认焦点不在其上（防误触）。
- **回滚前自动留快照**：确认后先把当前数据存成一份快照，再整份覆盖——退错了还能再退回来。真机验证：回滚后快照从 1 份变 2 份。
- 快照保留从「7 天、一天一份」升级为「7 天 + 最多 30 份」双保险；设置页「自动快照」改为「备份与回滚」入口。
- 移动端按钮顺序单独修正（不沿用编辑弹窗的 column-reverse），桌面/移动端一致。

## 三、真正的媒体卡 + 图片遮挡

`feat: 真正的媒体卡与图片遮挡（库内图片/音频嵌入、百分比遮挡区域、可点揭示）`

- 新增两种制卡方式：**媒体卡**（图片/音频真实嵌入，复习时显示/播放，不再是 `[图片：文件名]` 占位）与**图片遮挡**（Anki Image Occlusion）。
- 卡片新增 `media`（库内图片/音频路径）与 `occlusion`（图片 + 百分比坐标的遮挡区域）字段。
- 图片遮挡用百分比坐标画方块，不依赖拖拽——手机也能点开揭示；点方块 toggle 显隐，随后直接评级。

- 两种模式都不调 AI（内容来自用户文件）；AI 底层看图能力按采纳意见留给将来。
- 真机验证：媒体卡真实显示测试图、有「看答案」；遮挡卡显示遮罩块「?」，点开显示「长江」，并直接给出四档评级。

## 四、自定义卡片模板

`feat: 自定义卡片模板（受限字段模板，自选正反面字段，不开放手写 HTML）`

- 抽认卡可自定义正面/背面各显示哪些预定义字段（问句、原文、想法、章节、书名、图片、音频）。
- **受限模板**：按采纳意见不开放手写 HTML/CSS（注入面 + 手机排版不可控 + 样式作用域），字段按预定义顺序渲染。
- 卡片管理器每行加「自定义卡片模板」入口；两面都必填有内容的字段，清空即恢复默认。
- 真机验证：模板 `front:[book,question] / back:[text,comment]` 正面显示「围城 + 谁脸红了？」，点看答案后分隔线下显示「方鸿渐的脸红了起来 + 这段写得很妙」。

## 五、反向卡 + 兄弟卡不扎堆

`feat: 自制卡反向卡与兄弟卡同轮去重（group 关联、bury siblings、设置可关）`

- 自制抽认卡可**一键生成反向卡**（问答对调），复用 Anki 导入 `#rev` 口径，两张卡共享 `groupId`、反向卡 `reverseOf` 指向原卡。
- **兄弟卡不扎堆**（Anki bury siblings）：同组多张卡同一轮只出第一张，其余留到下一轮；不改排期、不删卡。设置页「复习节奏」加开关「兄弟卡不扎堆」（默认开）。
- 真机验证：生成反向卡后数据为 `c1`（谁脸红了？→ 方鸿渐）与 `c1#rev`（方鸿渐 → 谁脸红了？）同组；开始复习本轮只出 1 张，反向卡留到下一轮。
