# 更新日志

发布日期：2026-11-24

## ✨ 新增

- **停用名单** ：作者停掉的激活码会联网核对并当场降级，断网重启也贴不回来。
- **授权档案** ：是否被停用、为什么掉级、上次激活失败都写进本地数据，方便排查。
- **试用码门槛** ：试用码必须是最新版才能解锁，落后就先更新插件。
- **自定义请求头** ：自定义 AI 通道可以填附加请求头，兼容需要会话头的网关。
- **海外购买** ：购买与赞助按钮按界面语言分流，繁体和英文用户走海外店。

## ⚡ 优化

- **在线更新日志** ：更新日志改读在线的复习条目，远程有新条目不用等插件更新。
- **试用码提示** ：版本落后时明确提示先更新，不再笼统地要求联网。
- **联网说明** ：说明里写清首次激活与试用码的联网核对，不再宣称完全离线。

## 🐛 修复

- **鉴权头保护** ：自定义请求头不能再盖掉密钥，填错也不会把请求变成 401。
- **在线日志兼容** ：只有复习日志、没有阅读器日志的远程数据也能正常显示。
- **Claude 通道** ：Anthropic 协议真正走 /messages，带正确的鉴权头与流事件。

# 安装

1. 打开 **设置 → 第三方插件**，关闭安全模式。
2. 用 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 添加 `yeshimei/bz-review`，或手动下载 Release 里的 `main.js`、`manifest.json`、`styles.css`，放进 `<你的库>/.obsidian/plugins/bz-review/`。
3. 启用后左侧出现日历勾图标，点开就是复习计划。
