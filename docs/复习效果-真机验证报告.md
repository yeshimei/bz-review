## 1. 为什么这次能说明"复习效果"

不是只看界面能不能点，而是**同一库里同时放了 5 张处于不同记忆阶段的卡**，一次性看 FSRS-7 对每种阶段给出的下一次间隔是否符合预期——也就是它"排得对不对"。

| 卡 | 建档/阶段 | 初始三元组 | 观察点 |
|---|---|---|---|
| n1 | 新卡，从未复习 | ladder / stage 0 / S=1 | 首次 Good 是否走 1m→10m 步骤 |
| n2 | 新卡，已学完 1m 步 | ladder / stage 1 / S=3.92 / D=3.53 | 第二步 Good 是否毕业进 FSRS |
| m1 | 成熟卡 | fsrs / S=45 / D=5.2 / 复习 8 次 | 中等稳定性能否拉开间隔 |
| m2 | 高稳定卡 | fsrs / S=180 / D=4.1 / 复习 12 次 | 高稳定性是否排得更疏 |
| r1 | 重学卡 | relearn / S=15 / D=6.2 | 点 Good 是否毕业回 FSRS |

## 3. 一句话结论

> 同一轮复习里，FSRS-7 给出的间隔从 **11 分钟（新卡）到 1035 天（高稳定卡）**，相差约 8 万倍——它不是"所有卡排一样的节奏"，而是**每张卡按自己记得多牢来排**。越牢越疏、越难越密，这正是科学复习的核心。
